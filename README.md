# AI Workplace Productivity Assistant

## Project Overview
This application is a modern, responsive web-based AI assistant designed to automate everyday workplace tasks. Built as a single, integrated platform with a clean SaaS-style dashboard, it empowers professionals to save time and increase efficiency by leveraging AI for writing, summarizing, and planning. 

##  Core Features
The application includes the following tools (navigable via the sidebar):
*   **Smart Email Generator:** Drafts professional emails based on user prompts and supports multiple tones (Formal, Friendly, Persuasive).
*   **Meeting Notes Summarizer:** Processes long-form meeting notes to extract concise summaries, action items, and deadlines.
*   **AI Task Planner:** Takes a list of tasks and generates an organized, prioritized daily or weekly schedule.
*   **AI Research Assistant:** Summarizes topics or pasted articles and provides key insights and recommendations.
