# Thoughtful Workday Companion

Build a modern, responsive SaaS style web application called AI Workplace Productivity Assistant that helps professionals automate workplace tasks using AI. The design should be clean , professional and have a dark mode aesthetic. The application must inlude the following 4 feature via sidebar navigation: 1. Smart Emails Generator: An input area for the user to state what the email is about , a dropdown menu to select the tone(formal, Freindly, Persuasive), and a button to generate the email. include an editable output erea.  2. Meeting Nites Summarizer: A text area to paste long notes, a button to generate a summary. The output should clearly separate the summary, action items, and deadlines. include an editable out put area.  3. AI Research Assistance: An input area to paste an article or topic and a button to  generate a summary with key insights and recommendations. Include an editable output area.  4. AI Task Planner: An input area to list tasks, and a button to generate a prioritized daily or weekly schedule. Include an editable output area.  Important Requirements: Include a prominent, professional Responsible AI Diclaimer  at the bottom of the page or on each tool screen (e.g. AI generated content may be inaccurate. Please review carefully.)
